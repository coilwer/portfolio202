# Oleksandr Plotnikov — портфолио front-end разработчика

Личный сайт-портфолио Oleksandr Plotnikov, front-end разработчика. Одностраничный сайт на чистых HTML, CSS и JavaScript, без фреймворков и сборщиков. Сайт двуязычный (English / Русский), поддерживает светлую и тёмную темы.

**Демо:** https://<username>.github.io/<repo>/

## Возможности

- **Одностраничная структура** с плавной навигацией по секциям: About, Stack, Projects, Results, Process, FAQ, Contact.
- **Два языка**: переключатель EN / RU в шапке. Тексты переводятся через словарь в `script.js`, выбор сохраняется в `localStorage`.
- **Светлая и тёмная тема** с учётом системных настроек при первом визите; выбор сохраняется в браузере.
- **Анимированный фон на WebGL**: фрагментный шейдер рисует медленно движущуюся «жидкую» поверхность. Если WebGL недоступен, включается запасной CSS-градиент.
- **Доступность**: ссылка «Skip to content», видимый фокус, `aria`-атрибуты, поддержка `prefers-reduced-motion` (анимации отключаются).
- **SEO и разметка**: мета-теги, Open Graph, Twitter Card, JSON-LD (`schema.org/Person`), `robots`.
- **Hash-маршрутизация** для внутренних страниц: `#/privacy`, `#/cookies`, `#/case`.
- **Политика конфиденциальности и cookie** на двух языках. Сайт не использует cookie, аналитику и рекламу.

## Структура проекта


## Настройка

Все персональные данные задаются в объекте `CONFIG` в начале `script.js`:

```js
var CONFIG = {
  formUrl: "",          // ссылка на Google Form, оканчивается на /viewform
  email: "you@example.com",
  github: "username",   // без @ и без ссылки
  telegram: "username", // без @
  cv: "",               // URL PDF-резюме; кнопка «Download CV» появится, если указан
  repo: "",             // URL репозитория сайта; ссылка появится в футере
  youtubeId: ""         // id видео на YouTube; появится кнопка проигрывания
};
```

Пустое значение скрывает соответствующий элемент, поэтому его можно не заполнять.

### Проекты

Массив `PROJECTS` в `script.js` создаёт карточки в секции Projects:

```js
var PROJECTS = [{
  name: "Task List",
  description: "Краткое описание проекта.",
  repo: "https://github.com/.../task-list",
  demo: "https://.../task-list/",
  tags: ["JavaScript", "localStorage", "GitHub Pages"],
  caseStudy: true   // ссылка на страницу #/case
}];
```

Пока массив пуст, секция Projects скрыта.

### Отзывы

Массив `TESTIMONIALS` добавляет карточки отзывов в секцию Results:

```js
var TESTIMONIALS = [{
  quote: "Текст отзыва",
  name: "Имя",
  role: "Должность, компания",
  metric: "Результат"
}];
```

### Форма заявки

Если указать `formUrl` с ссылкой на Google Form, форма встроится в секцию Contact через iframe. Для других ссылок показывается кнопка перехода.

### Переводы

Русские версии текстов из HTML хранятся в объекте `RU` в `script.js`. Ключом служит исходная английская строка, значением её перевод. При добавлении нового текста с переводом нужно добавить пару в `RU`. Тексты, у которых есть блок `data-l="ru"` в HTML, переключаются вместе с языком.

## Запуск локально

Сайту не нужны сборка и зависимости. Достаточно открыть `index.html` в браузере или запустить любой статический сервер:

```bash
# например, через Python
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Деплой на GitHub Pages

1. Загрузите файлы в репозиторий.
2. Откройте **Settings → Pages**.
3. В поле **Source** выберите ветку (например, `main`) и корневую папку `/ (root)`.
4. Сохраните. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Не забудьте заменить адрес в мета-тегах `og:image` и `twitter:image` в `index.html` на реальный адрес сайта (полный `https://...`).

## Браузеры

Современные браузеры с поддержкой ES5, `IntersectionObserver` и WebGL. Без WebGL сайт остаётся полностью рабочим, меняется только фон.
